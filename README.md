Bu proje, açık hava durumu API'si kullanarak seçilen herhangi bir şehrin anlık hava durumunu gösteren basit ve işlevsel bir web uygulamasıdır. 
Kullanıcı şehir ismini girer, uygulama API üzerinden veriyi çeker ve ekrana güncel bilgileri yansıtır.
